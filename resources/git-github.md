# Git & GitHub Resources

A curated collection of Git documentation, interactive learning games, branching visualizers, and GitHub CLI/Actions tools.

## Interactive Learning Games & Visualizers

| Resource | URL | Description |
|---|---|---|
| Oh My Git! | https://ohmygit.org/ | An open-source game for learning Git using real visual graphs |
| Learn Git Branching | https://learngitbranching.js.org/ | The most visual and interactive way to learn Git on the web |
| Git Immersion | https://gitimmersion.com/ | A guided tour that walks through the fundamentals of Git step-by-step |
