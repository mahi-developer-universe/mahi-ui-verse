# Categories & Architecture

**Mahi UI Verse** organizes resources into logical directories and categories so frontend developers, designers, and creators can discover the tools they need effortlessly.

---

## Architecture Overview

```text
mahi-ui-verse/
├── categories/       # Category index and cross-references
├── ui/               # Component libraries, design systems, charts, animations, templates, generators
├── ux/               # Prototyping, wireframing, UX research, usability tools
├── frontend/         # Frontend libraries, frameworks, developer tools
├── inspiration/      # Design galleries, website showcases, landing page archives, portfolios
├── resources/        # Icons, typography, illustrations, media, free assets, master directory
├── demos/            # Live interactive demonstrations and playgrounds
├── videos/           # UI showcases, tutorials, frontend walkthroughs
└── docs/             # Curation policies, submission standards, maintenance procedures
```

---

## Detailed Category Breakdown

### 1. UI (`ui/`)
- **Component Libraries** (`ui/component-libraries.md`): Pre-built accessible components for React, Vue, Svelte, and vanilla web stacks (e.g., shadcn/ui, Cult UI, Forge UI).
- **Design Systems** (`ui/design-systems.md`): Comprehensive corporate and open-source design systems (e.g., Apple HIG, Material Design, Carbon).
- **Charts & Data Visualization** (`ui/charts.md`): Charting libraries, canvas renderers, and interactive visualization kits (e.g., Evil Charts, Tremor, Recharts).
- **Animations & Motion** (`ui/animations.md`): Motion libraries, physics engines, and spring animations (e.g., Motion Primitives, Framer Motion, GSAP).
- **UI Generators** (`ui/ui-generators.md`): Generators for shadows, glassmorphism, buttons, and layouts.
- **Templates** (`ui/templates.md`): Production-ready website and application starter templates.

### 2. UX (`ux/`)
- **UX Tools** (`ux/ux-tools.md`): User experience suites and interaction design platforms.
- **Wireframing** (`ux/wireframing.md`): Low-fidelity sketching, wireframing, and structure kits.
- **Prototyping** (`ux/prototyping.md`): Interactive prototypes, transition models, and user flows.
- **User Research** (`ux/user-research.md`): Heatmaps, recording, survey tools, and user testing.

### 3. Frontend (`frontend/`)
- **Developer Tools** (`frontend/developer-tools.md`): Browser extensions, bundlers, performance debuggers, and IDE enhancements.
- **Libraries** (`frontend/libraries.md`): Utility libraries, state management, and DOM assistants.
- **React, CSS, JavaScript** (`frontend/`): Domain-specific frontend guides and references.

### 4. Inspiration (`inspiration/`)
- **Design Inspiration** (`inspiration/design-inspiration.md`): Curated master directory of 347+ design references, SaaS patterns, and mobile designs.
- **Website Inspiration** (`inspiration/website-inspiration.md`): Top-tier web design awards, galleries, and experimental web experiments.
- **Landing Pages** (`inspiration/landing-pages.md`): High-converting SaaS, product, and launch pages.
- **Portfolio Inspiration** (`inspiration/portfolio-inspiration.md`): Standout developer and designer portfolios.

### 5. Resources (`resources/`)
- **Master Website Directory** (`resources/website-directory.md`): Alphabetical collection of 458 curated frontend/UI tools.
- **Curated Featured Resources** (`resources/curated-resources.md`): High-signal highlighted tools and developer practice games.
- **Icons** (`resources/icons.md`), **Fonts** (`resources/fonts.md`), **Illustrations** (`resources/illustrations.md`), **Images** (`resources/images.md`), **Free Assets** (`resources/free-assets.md`).
