# Categories & Architecture

**Mahi UI Verse** organizes resources into logical directories and categories so frontend developers, designers, and creators can discover the tools they need effortlessly.

---

## Architecture Overview

```text
mahi-ui-verse/
├── categories/       # Category index and cross-references
├── ui/               # Component libraries, design systems, charts, animations, templates, generators, web showcases, landing pages, portfolios, creative tools
├── ux/               # Prototyping, wireframing, UX research, usability tools, user flows
├── frontend/         # Frontend libraries, frameworks, developer tools, languages, performance, testing
├── resources/        # Icons, typography, illustrations, media, free assets, master directory, AI tools, devops, git
├── demos/            # Live interactive demonstrations and playgrounds
├── videos/           # UI showcases, tutorials, frontend walkthroughs
└── docs/             # Curation policies, submission standards, maintenance procedures
```

---

## Detailed Category Breakdown

### 1. UI (`ui/`)
- **Component Libraries** (`ui/component-libraries.md`): Pre-built accessible components for React, Vue, Svelte, and vanilla web stacks (e.g., shadcn/ui, Cult UI, Forge UI).
- **Design Systems** (`ui/design-systems.md`): Comprehensive corporate and open-source design systems (e.g., Apple HIG, Material Design, Carbon).
- **Charts & Data Visualization** (`ui/charts.md`): Charting libraries, canvas renderers, and interactive visualization kits (e.g., Evil Charts, Tremor, Recharts).
- **Animations & Motion** (`ui/animations.md`): Motion libraries, physics engines, and spring animations (e.g., Motion Primitives, Framer Motion, GSAP).
- **UI Generators** (`ui/ui-generators.md`): Generators for shadows, glassmorphism, buttons, patterns, and layouts.
- **Templates** (`ui/templates.md`): Production-ready website and application starter templates.
- **Web Design Showcases** (`ui/web-showcases.md`): Award-winning web designs, Awwwards winners, and experimental web showcases.
- **Landing Pages & SaaS** (`ui/landing-pages.md`): High-converting SaaS, product, and launch pages.
- **Portfolios & Showcases** (`ui/portfolios.md`): Standout developer, designer, and agency portfolios.
- **Creative Tools & Utilities** (`ui/creative-tools.md`): Online generators, design utilities, canvas tools, and visual editors.
- **Marketing & Pitch Decks** (`ui/marketing-ui.md`): Pitch decks, email design archives, and marketing UI.
- **Motion Design & 3D** (`ui/motion-design.md`): Interactive 3D web experiences, easing tools, and motion experiments.
- **Branding & Identity** (`ui/branding-design.md`): Logo directories, identity systems, and brand assets.
- **Mobile & App Design** (`ui/mobile-design.md`): Mobile UI patterns, iOS/Android screens, and app design archives.
- **UI Patterns & Elements** (`ui/ui-patterns.md`): Specific interface micro-patterns, footers, navbars, and 404 pages.

### 2. UX (`ux/`)
- **UX Tools** (`ux/ux-tools.md`): User experience suites and interaction design platforms.
- **UX User Flows & Case Studies** (`ux/ux-flows.md`): User flow teardowns, onboarding benchmarks, and UX case studies.
- **Wireframing** (`ux/wireframing.md`): Low-fidelity sketching, wireframing, and structure kits.
- **Prototyping** (`ux/prototyping.md`): Interactive prototypes, transition models, and user flows.
- **User Research** (`ux/user-research.md`): Heatmaps, recording, survey tools, and user testing.

### 3. Frontend (`frontend/`)
- **Developer Tools** (`frontend/developer-tools.md`): Browser extensions, bundlers, performance debuggers, and IDE enhancements.
- **Libraries** (`frontend/libraries.md`): Utility libraries, state management, and DOM assistants.
- **React, CSS, JavaScript, TypeScript, Performance, Testing, Accessibility** (`frontend/`): Domain-specific frontend guides and references.

### 4. Resources (`resources/`)
- **Master Website Directory** (`resources/website-directory.md`): Alphabetical collection of 458 curated frontend/UI tools.
- **Curated Featured Resources** (`resources/curated-resources.md`): High-signal highlighted tools and developer practice games.
- **Icons** (`resources/icons.md`), **Fonts** (`resources/fonts.md`), **Illustrations** (`resources/illustrations.md`), **Images** (`resources/images.md`), **Free Assets** (`resources/free-assets.md`), **AI Tools** (`resources/ai-tools.md`), **Git & GitHub** (`resources/git-github.md`), **DevOps** (`resources/devops.md`).
