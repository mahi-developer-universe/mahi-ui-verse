# Quality Standards

At **Mahi UI Verse**, we maintain strict quality standards to ensure our directory serves as a world-class, human-curated hub for frontend engineers, UI/UX designers, and creative technologists.

---

## The Core Principles

```text
Curated > Copied
Verified > Guessed
Useful > Numerous
Accessible > Opaque
```

---

## 1. Documentation & Formatting Standards

- **Standard Markdown Formatting**: All entries must follow normalized markdown format:
  ```markdown
  1. Resource Name — [https://example.com/](https://example.com/)
  ```
  Or in tabular records:
  ```markdown
  | Resource | URL | Description |
  ```
- **Sequential & Clean Numbering**: Numbered directories must strictly ascend without gaps or duplicates (`1, 2, 3...`).
- **Alphabetical Sorting**: Resource indexes are sorted case-insensitively (`A–Z`, symbols/numbers under `#`).
- **Clean Descriptions**: Avoid superlatives ("The greatest framework in history!"). Use objective, informative descriptions ("Accessible React component library with Tailwind CSS styling").

---

## 2. Link & Security Standards

- **Mandatory HTTPS**: All URLs must use `https://` unless the target host strictly does not support TLS.
- **Zero Tracking Artifacts**: URLs must be stripped of tracking query parameters (`?utm_source=...`, `?ref=...`, `?fbclid=...`, `?twclid=...`) unless a query parameter is functionally required to navigate to a specific tool or tab.
- **Valid Hostnames & Clean TLDs**: No URL shorteners (`bit.ly`, `tinyurl.com`, `t.co`) or intermediate redirect trackers.
- **Security Vetting**: Sites distributing malware, crypto scams, aggressive popups, or phishing content will be rejected or purged immediately.

---

## 3. Metadata Completeness

When adding entries to the canonical registry:
- **Canonical URL**: Preserved without trailing slashes.
- **License**: Disclosed where discernible (`MIT`, `Apache-2.0`, `GPL-3.0`, `Freemium`, `Proprietary`).
- **Pricing**: Accurately identified (`Free`, `Freemium`, `Paid`, `Open Source`).
- **Category & Tags**: Correct semantic classification aligned with [docs/CATEGORIES.md](CATEGORIES.md).
