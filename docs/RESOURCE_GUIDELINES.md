# Resource Guidelines

This document outlines the principles, evaluation criteria, and categorization rules for adding resources to **Mahi UI Verse**.

---

## 1. Scope & Focus

Mahi UI Verse is a human-curated collection specifically dedicated to:
- **UI Components & Component Libraries**: React, Vue, Svelte, Web Components, and Vanilla JS UI kits.
- **Design Systems & Primitives**: Design tokens, typography engines, color palettes, and accessible foundations.
- **Micro-interactions & Animations**: Framer Motion, GSAP, CSS animations, canvas effects, and transitions.
- **Generators & Creative Tools**: Gradient generators, SVG tools, pattern makers, shaders, and halftone tools.
- **Design Inspiration & Galleries**: Curated showcases of landing pages, SaaS products, dark mode designs, and micro-interactions.
- **Developer & Practice Tools**: Modern web development utilities, learning games, and testing platforms.

---

## 2. Inclusion Criteria

To be accepted into the directory, every resource must satisfy the following:
1. **Utility & High Value**: Solves real challenges for frontend developers, UI/UX designers, or product teams.
2. **Operational Status**: Must be live, responsive, and functional (no placeholder domains or "Coming Soon" splash screens).
3. **Canonical Identity**: Must point to the canonical official product/project URL or official GitHub repository.
4. **Transparent Terms**: Commercial restrictions, open-source licenses, or freemium pricing must be clearly discernible.
5. **Quality Design**: The resource itself should showcase solid aesthetics, clean UX, and professional polish.

---

## 3. What We Do Not Include

- **Duplicate URLs & Redundant Mirrors**: Secondary mirrors of already cataloged tools without distinct value.
- **SEO Farms & Affiliate Traps**: Link aggregators created primarily to harvest referral clicks with little original utility.
- **Broken / Abandoned Projects**: Dead URLs, expired SSL certificates, parked domains, or unmaintained prototypes.
- **Generic Commercial Advertisements**: Software that offers no free tier, trial, live playground, or public documentation.
- **Low-Quality Content**: Auto-generated AI junk, copied component libraries with no licensing or originality.

---

## 4. Preserving Deep Links & Specific Tools

When a resource provides specialized value on a specific page (e.g., a background generator sub-tool, an interactive component playground, or an icon set), **preserve the specific URL** rather than reducing it to a generic homepage.
