# Resource Format

Use consistent Markdown entries across all categories.

## Example

### Evil Charts
- **Website:** https://evilcharts.com/
- **Category:** Data visualization
- **Description:** A collection of chart components and examples for building data-rich interfaces.
- **Documentation:** https://evilcharts.com/docs
- **Demo:** https://evilcharts.com/docs/recharts/area-chart/static
- **Video:** Add only a relevant, verified walkthrough.
- **License and pricing:** Check the current official source before use.
