# How to Add a Resource

1. Find the official website.
2. Check whether the URL already exists in the catalogue.
3. Choose the most relevant category.
4. Write a short, original description.
5. Add a direct demo or playground if one exists.
6. Add a tutorial video only when it is relevant.
7. Verify licensing, pricing, and access notes where applicable.
8. Check that all Markdown links work.
9. Run `.\scripts\validate-resources.ps1`.
10. Submit the change with a clear commit message.

## Resource template

- **Name:** Resource name
- **Category:** UI, UX, frontend, inspiration, assets, or learning
- **Official website:** Canonical URL
- **Description:** What it does and who it helps
- **Demo:** Direct demo link, if verified
- **Video:** Relevant walkthrough, if available
- **Pricing/license:** Verified notes or `Not checked`
