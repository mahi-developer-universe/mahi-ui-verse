# Security Review Checklist

Before committing:
- [ ] No passwords, tokens, API keys, or private keys are included.
- [ ] No personal data or private logs are included.
- [ ] New dependencies have been reviewed.
- [ ] External links use HTTPS where supported.
- [ ] Scripts do not execute downloaded code without verification.
- [ ] User-provided input is handled safely in project code.
- [ ] Documentation examples use placeholder credentials.
- [ ] Security scans have been reviewed.
- [ ] Backups and generated files are excluded where appropriate.
