# Mahi UI Verse — Registry Category Index

The canonical registry (`registry/resources.json`) categorizes all 458 verified resources under five primary domain categories:

---

## 1. UI (`ui`)

Pre-built components, design systems, visual showcases, templates, generators, and creative tools.

- **Component Libraries** — Pre-built accessible components for modern web stacks
- **Design Systems** — Comprehensive design frameworks and token systems
- **Charts & Data Visualization** — Charting libraries, canvas renderers, and metrics kits
- **Animations & Motion** — Motion engines, transitions, and micro-interactions
- **UI Generators** — Layout, gradient, shadow, and palette generators
- **Templates** — Website, dashboard, and application starter templates
- **Web Design Showcases** — Award-winning showcases and site collections
- **Landing Pages & SaaS** — High-converting landing pages and SaaS interfaces
- **Portfolios & Showcases** — Creative developer, agency, and designer portfolios
- **Creative Tools & Utilities** — Online design utilities, SVG tools, and canvas playgrounds
- **Marketing & Pitch Decks** — Marketing UI, pitch deck libraries, and launch templates
- **Motion Design & 3D** — Interactive 3D web experiences, easing tools, and WebGL
- **Branding & Identity** — Brand asset archives, logo directories, and guidelines
- **Mobile & App Design** — Mobile UI patterns, iOS/Android screens, and app design
- **UI Patterns & Elements** — Specific interface patterns, navbars, footers, and modals

---

## 2. UX (`ux`)

User experience, interaction design, flow teardowns, and user testing.

- **UX Tools** — Comprehensive interaction design and user testing suites
- **User Flows & Case Studies** — Onboarding benchmarks, UX teardowns, and flow patterns
- **Wireframing** — Low-fidelity wireframing and ideation kits
- **Prototyping** — High-fidelity prototyping and interactive transition tools
- **User Research** — Usability testing, user session recording, and customer surveys

---

## 3. Frontend (`frontend`)

Frontend engineering guides, language standards, performance benchmarks, and toolchains.

- **Developer Tools** — Browser devtools, bundlers, linters, and developer utilities
- **Libraries** — Utility libraries, DOM assistants, and UI engines
- **Frameworks & Languages** — React, TypeScript, JavaScript, CSS
- **Accessibility (a11y)** — WCAG compliance tools, screen-reader testing, audit suites
- **Web Performance** — Core Web Vitals, bundle analyzers, and page speed profilers
- **Testing & QA** — Unit, end-to-end, and visual regression testing frameworks
- **State Management** — Modern client and server state orchestration

Design assets, developer learning games, and curated directories.

## 5. Demos & Videos (`demos`, `videos`)

Interactive playgrounds and visual walkthroughs.
