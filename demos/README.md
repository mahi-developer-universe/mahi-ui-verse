# Resource Categorization Rules

## UI

### Components

Buttons, inputs, cards, modals, menus, tabs, accordions.

### Design Systems

Design tokens, component systems, design-system documentation.

### Charts

Charts, graphs, data visualization.

### Animations

Motion, transitions, animation libraries.

### Generators

Backgrounds, gradients, patterns, shapes, visual generators.

## UX

Research, testing, wireframes, prototypes, user flows, accessibility.

## Frontend

React, Next.js, Vue, Angular, Svelte, JavaScript, TypeScript, CSS, testing and performance.

## Design

Icons, fonts, typography, illustrations, images, 3D, gradients and patterns.

## Inspiration

Websites, portfolios, landing pages, dashboards, mobile apps and e-commerce.

## Learning

Courses, tutorials, documentation, books, YouTube and cheat sheets.

## Important

A resource should have ONE primary category in the canonical registry.

It may have multiple tags.

Example:

Category:
ui

Subcategory:
charts

Tags:
charts
