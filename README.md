## How to Use

1. Open a category.
2. Visit the official website.
3. Explore its components, examples, or playground.
4. Follow the documentation to integrate a resource.
5. Check its license before using it in a project.

## Adding a Resource

Use this format:

`- [Resource Name](https://example.com/) — Short description`

Include separate demo and video links only when available and verified.
