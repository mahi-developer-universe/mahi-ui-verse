# Contributing to Mahi UI Verse

Mahi UI Verse is a curated developer-resource directory.

## Before submitting

Check:

- [ ] Resource is not already listed
- [ ] Official website
- [ ] Working URL
- [ ] Correct category
- [ ] Useful description
- [ ] Demo verified
- [ ] Documentation verified
- [ ] GitHub verified
- [ ] Video verified
- [ ] Pricing verified
- [ ] License verified
