# Contributing to Mahi UI Verse

Thanks for helping grow this UI/UX and frontend resource directory.

## Before contributing
- Check for duplicate URLs.
- Prefer official websites and documentation.
- Include useful descriptions, not link-only entries.
- Verify demo and video links.
- Do not guess pricing, licensing, or feature support.

## Suggested workflow
1. Create a branch.
2. Add or update the relevant Markdown file.
3. Run `.\scripts\validate-resources.ps1`.
4. Review the diff.
5. Submit a pull request with a descriptive summary.
