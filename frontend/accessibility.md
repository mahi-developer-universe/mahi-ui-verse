# Accessibility Resources (a11y)

A curated collection of web accessibility guides, component primitives, testing tools, and WCAG standards for building inclusive frontend experiences.

---

## Standards & Guidelines

| Resource | URL | Description |
|---|---|---|
| W3C WAI WCAG 2.2 | https://www.w3.org/WAI/standards-guidelines/wcag/ | Official Web Content Accessibility Guidelines documentation |
| The A11Y Project | https://www.a11yproject.com/ | Community-driven resource to make digital accessibility easier |
| MDN Accessibility | https://developer.mozilla.org/en-US/docs/Learn/Accessibility | Practical web accessibility tutorials and reference by Mozilla |
| Inclusive Components | https://inclusive-components.design/ | Pattern library focused on building robust, accessible UI components |

## Accessible Component Foundations

| Resource | URL | Description |
