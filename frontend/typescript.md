# TypeScript Resources

A curated collection of TypeScript documentation, type utility libraries, interactive learning sandboxes, and best practices.

---

## Official Documentation & Guides

| Resource | URL | Description |
|---|---|---|
| TypeScript Official | https://www.typescriptlang.org/ | Official documentation, language specification, and type references |
| TypeScript Playground | https://www.typescriptlang.org/play | Official interactive sandbox for running, compiling, and testing TypeScript |
| Total TypeScript | https://www.totaltypescript.com/ | Comprehensive tutorials and interactive workshops by Matt Pocock |
| TypeScript Handbook | https://www.typescriptlang.org/docs/handbook/intro.html | Authoritative guide to writing scalable typed JavaScript |

---

## Type Utilities & Validation

| Resource | URL | Description |
|---|---|---|
| Zod | https://zod.dev/ | TypeScript-first schema declaration and runtime data validation with static type inference |
| Type-Fest | https://github.com/sindresorhus/type-fest | A collection of essential, high-utility TypeScript types |
| ts-reset | https://github.com/total-typescript/ts-reset | Rule set to make TypeScript's built-in global types more realistic and safer |
| Type Challenges | https://github.com/type-challenges/type-challenges | Collection of TypeScript type challenges to practice advanced generic type skills |
