# Web Performance Resources

A curated list of Core Web Vitals guides, page-speed benchmarks, asset optimizers, bundle analyzers, and frontend performance profilers.

---

## Core Web Vitals & Metrics

| Resource | URL | Description |
|---|---|---|
| web.dev Core Web Vitals | https://web.dev/explore/learn-core-web-vitals | Essential metrics for a healthy website (LCP, INP, CLS) by Google |
| PageSpeed Insights | https://pagespeed.web.dev/ | Real-world Chrome User Experience Report (CrUX) and lab performance diagnostics |
| GTmetrix | https://gtmetrix.com/ | Comprehensive webpage speed analysis, waterfall breakdowns, and actionable tips |
| WebPageTest | https://www.webpagetest.org/ | In-depth website speed tests from multiple locations using real browsers |

## Image & Asset Optimization

| Resource | URL | Description |
|---|---|---|
| Squoosh | https://squoosh.app/ | Browser-based image compression using modern codecs (WebP, AVIF) by Google Chrome Labs |
| TinyPNG | https://tinypng.com/ | Smart WebP, PNG, and JPEG image compression service |
| Shrink Media | https://www.shrink.media/ | Intelligent tool to reduce image file sizes without compromising visual quality |
| SVGOMG | https://jakearchibald.github.io/svgomg/ | Web GUI for SVGO to optimize, sanitize, and minify SVG vector graphics |
