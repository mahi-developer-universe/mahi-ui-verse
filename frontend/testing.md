# Frontend Testing & Quality Assurance

A curated list of unit, component, end-to-end, and visual regression testing frameworks for frontend applications.

---

## Unit & Component Testing

| Resource | URL | Description |
|---|---|---|
| Vitest | https://vitest.dev/ | Next-generation fast unit test framework powered by Vite |
| Jest | https://jestjs.io/ | Delightful JavaScript testing framework with a focus on simplicity |
| React Testing Library | https://testing-library.com/docs/react-testing-library/intro/ | Simple and complete testing utilities that encourage good testing practices |
| Testing Library | https://testing-library.com/ | UI testing utilities focused on querying the DOM the way users interact with it |

---

## End-to-End (E2E) Testing

| Resource | URL | Description |
|---|---|---|
| Playwright | https://playwright.dev/ | Reliable end-to-end testing for modern web apps across Chromium, Firefox, and WebKit |
| Cypress | https://www.cypress.io/ | Fast, easy, and reliable testing for anything that runs in a browser |
| Tester Army | https://tester.army/e2e | End-to-end testing platform and resource guide |

---

## Visual Testing & Component Sandboxes

| Resource | URL | Description |
|---|---|---|
| Storybook | https://storybook.js.org/ | Frontend workshop for building UI components and pages in isolation |
| Chromatic | https://www.chromatic.com/ | Automated visual regression testing and component review powered by Storybook |
