# State Management Resources

A curated list of state management libraries, server cache synchronizers, and reactive primitives for frontend applications.

---

## Client State Management

| Resource | URL | Description |
|---|---|---|
| Zustand | https://zustand.docs.pmnd.rs/ | Small, fast, and scalable bearbones state-management solution for React |
| Jotai | https://jotai.org/ | Primitive and flexible state management for React based on atomic primitives |
| Redux Toolkit | https://redux-toolkit.js.org/ | The official, opinionated, batteries-included toolset for efficient Redux development |
| XState | https://stately.ai/docs/xstate | Actor model and state machines for reliable, robust frontend logic |
| MobX | https://mobx.js.org/ | Simple, scalable state management powered by transparent functional reactivity |

---

## Server State & Asynchronous Data Fetching

| Resource | URL | Description |
